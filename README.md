# Mi primera contribución

Este repo se armó para la exposición sobre Open Source del jueves 13 de agosto. La idea es simple: **hacer, en cinco minutos, el mismo proceso que usan millones de personas para contribuir a proyectos reales.**

No hace falta saber programar. No hace falta más que una cuenta de GitHub.

## Qué puedes hacer acá

Elige uno (o los tres, si quieres):

1. **Agrega tu nombre** en [`CONTRIBUTORS.md`](./CONTRIBUTORS.md) — el ejercicio clásico de primera contribución.
2. **Suma un dato curioso sobre open source** en [`curiosidades.md`](./curiosidades.md).
3. Si programas: arregla el bug intencional en [`bonus/fix_me.py`](./bonus/fix_me.py).

## Cómo se hace, paso a paso

1. Arriba a la derecha de este repo en GitHub, haz clic en **Fork**. Eso crea tu propia copia.
2. En tu copia, entra al archivo que quieras editar y haz clic en el **lápiz** (editar) arriba a la derecha.
3. Haz tu cambio.
4. Al final de la página, elige **"Create a new branch and start a pull request"** y confirma.
5. GitHub arma automáticamente un **Pull Request (PR)** — un pedido para que tu cambio se incorpore al repo original.
6. Listo. Eso es todo el proceso que usa cualquier persona para contribuir a un proyecto que no es suyo.

No necesitas instalar Git ni usar la terminal — GitHub permite hacer todo esto desde el navegador cuando el cambio es a un archivo de texto.
